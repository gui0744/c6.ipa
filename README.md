# Banking App — White-label demo

Este repositório foi substituído pelo starter do **Banking App**. O código completo está no arquivo `banking-app-monorepo.zip`; extraia o conteúdo para obter as pastas `mobile/`, `backend/`, `admin-panel/`, `documentation/` e `infrastructure/`.

- App Flutter demonstrativo com dados fictícios e idiomas pt-BR, inglês e chinês simplificado.
- API Node.js/TypeScript de demonstração.
- Workflow GitHub Actions para validação.

**Importante:** ainda é um starter, não um banco operacional. Não realiza Pix, transferências ou movimentação de dinheiro. Não contém integração bancária real, credenciais, certificados ou assinatura de IPA. Use identidade visual própria e integrações autorizadas.

## Estrutura
O ZIP contém a pasta `banking-app/` com todo o monorepo.
